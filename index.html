HTML + CSS + JavaScript Self Assessment

Most useful tags in HTML

  • <a> - defines a hyperlink
  • <body> - defines the content of a web page
  • <button> - defines an interactive button used to trigger an action
  • <div> - defines a generic container and is useful when used with CSS
  • <footer> - defines the footer of the web page
  • <form> - defines a section where information can be submitted
  • <head> - defines the page's metadata
  • <html> - defines the root level of the document
  • <img> - defines an embedded image
  • <p> - defines a paragraph

Important SEO tags

  • <title> - used to determine the page subject for search engines
  • <meta> - can be used to create a description for the page
  • <h1> to <h6> - used to show page divisions and may be used to index different sections of the page
  • <img src="" alt=""> - the alt attribute of an img tag helps make images searchable by search engines
